From clone to the arena

How a bot gets made

  1. Get the code

    The rules, the trainer and the tools are all in one open repo (MIT). You need Rust and uv.

    git clone https://github.com/aiocean/arena
cd arena/train && uv sync
uv run maturin develop --release \
  -m ../crates/pixfx-duel-py/Cargo.toml
    github.com/aiocean/arena

  2. Train

    Fine-tune from the shipped AI with PPO, or train any model you like, and export it as ONNX.

    uv run python ppo.py --run mine \
  --init ../crates/pixfx-duel/weights/policy.onnx
uv run python export.py runs/mine/last.pt --out mine.onnx
    Training

  3. Test

    Build it into a bot module, then run the submission checks and the entry bar.

    cargo run -p arena-bot --example onnx -- mine.onnx mine.wasm
cargo run --release -p arena-bot --features host \
  --example check -- mine.wasm
    The bot

  4. Watch & submit

    Drop your module into a corner on this page and it fights at once. A seed is a replay: same bots, same fight, every machine.

    mine.wasm  vs  rival.wasm
seed 201521
